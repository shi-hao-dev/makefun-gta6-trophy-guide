# GTA 6 Trophy Guide & Tracker

An offline, open-source web app: a tracker over all 55 official GTA VI trophies
(name, description, grade), with a checklist saved in the browser (export/import),
filters, a spoiler setting, a roadmap to the platinum, and a guide to each trophy
in our own words, with sources cited.

Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty
($250 in USDC).
